THE STORY

Operator first. Builder always.

I’ve run the floor

Five years as head of manufacturing, second in command of the whole operation — people, throughput, cost, quality, and the systems that keep production moving when nobody’s watching. Assembly Floor OS exists because I lived the problem it solves.

I’ve built with my hands

Before software: a full off-grid home inside a cargo trailer that I lived in for six months, commissioned lighting for NYC bars, custom furniture in Brooklyn. I don’t hand over things I haven’t had to live inside — that’s why the software ships and doesn’t break.

Now I build systems that run themselves

Everything on the line runs on the same discipline: a knowledge vault every agent reads and writes, a stable dev surface for every project, and one decision to ship. Capture → build on dev → ship to live. Same three moves, every product.
